# De l'océan à la ville

Site exemple de scrollytelling (Portugal) pour les cours de web design.
Site statique : HTML, CSS et JavaScript, avec GSAP 3.12.5 chargé depuis cdnjs.

## Mettre en ligne sur Vercel

    npx vercel        # première fois : connexion dans le navigateur, puis aperçu
    npx vercel --prod # mise en ligne finale

Aucune étape de build : Vercel sert les fichiers tels quels.
